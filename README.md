# Resineo by Apavi Green — Canarias

Sitio oficial de la concesión de Résineo (revestimiento de suelo en resina + grava natural)
para las Islas Canarias, distribuido por Apavi Green.

## Desarrollo

Sitio estático sin build. Abre cualquier `.html` directamente en el navegador o sírvelo con
cualquier servidor estático.
